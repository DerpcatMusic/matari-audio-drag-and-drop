# Security policy

Please report vulnerabilities through GitHub's private vulnerability reporting
flow in the repository Security tab. Do not open a public issue for a suspected
memory-safety, native-handle, path-disclosure, or protocol-spoofing problem.

Security fixes target the latest released patch line. Reports should include the
Matari version or commit, operating system, window backend, plug-in host when
applicable, and the smallest reproduction that demonstrates the boundary
failure.
